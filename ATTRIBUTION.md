# Mapping and source attribution

## Administrative geometry

The live interactive map fetches the **China Atlas (`cn-atlas`) version 0.1.2**, a derivative administrative-boundary dataset provided by [BarbarossaWang/cn-atlas](https://github.com/BarbarossaWang/cn-atlas), whose README attributes original boundary shapefiles to [ruiduobao/shengshixian.com](https://github.com/ruiduobao/shengshixian.com). Package metadata describes the redistribution as **ISC-licensed**. The site fetches data rather than redistributing a local copy. Inspect the source dataset and its upstream reuse rights before any further publishing or republication, especially if an official cartographic standard is required.

The map is used as an *illustrative province selector* for research. The Observatory does not independently validate the boundary lines, and does not take a position on disputed boundaries or sovereignty.

Source links: `https://unpkg.com/cn-atlas@0.1.2/provinces.json` (primary), `https://cdn.jsdelivr.net/npm/cn-atlas@0.1.2/provinces.json` (fallback).

## Policy sources

All policy records link to original Chinese government or government-agency documents and include document IDs or titles. Links, dates and evidence summaries appear in `data/policies.json`. Summaries are original short paraphrases written for the tracker. The project does not reprint full official texts.

## Typography

Uses DM Sans and Libre Baskerville from Google Fonts when available, with installed system-font fallbacks. The website does not bundle or redistribute the font files.
